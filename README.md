# ميزان | Mizan

ميزان تطبيق Flutter Web لمتابعة الدخل والمصروفات والميزانيات الشخصية بالريال السعودي. يدعم العربية والإنجليزية، ويحفظ البيانات في SQLite داخل المتصفح.

## التشغيل من VS Code

افتح مجلد المشروع الذي يحتوي على `pubspec.yaml` في VS Code، ثم افتح الطرفية المدمجة وشغّل:

```powershell
flutter pub get
flutter run -d chrome --web-hostname=127.0.0.1 --web-port=8765
```

يفتح Flutter التطبيق في Chrome. استخدم العنوان والمنفذ نفسيهما للوصول إلى بياناتك عند استعمال ملف تعريف المتصفح نفسه. لحفظ البيانات بين جلسات التطوير في متصفحك المعتاد، بدّل `-d chrome` بـ `-d web-server` وافتح http://127.0.0.1:8765 في ذلك المتصفح.

لبناء نسخة إنتاج بأصول محلية استخدم `flutter build web --no-web-resources-cdn`. شغّل `flutter analyze` و`flutter test` للتحقق من المشروع.

ملفا `web/sqlite3.wasm` و`web/sqflite_sw.js` مرفقان. عند ترقية SQLite، أعد توليد العامل والملف عبر `dart run sqflite_common_ffi_web:setup --force` وحدد إصدار WebAssembly المطابق لـ SQLite المحلول في `pubspec.lock`.

## الوظائف

- لوحة رصيد ودخل ومصروف شهري، وسجل يدعم البحث والتصفية والفرز.
- تصنيفات افتراضية ومخصصة، ورسوم توزيع الإنفاق والمقارنة على ستة أشهر.
- ميزانية شهرية إجمالية وبحسب التصنيف، مع تنبيهات عند بلوغ ٨٠٪ وعند تجاوز الحد.
- معاملات شهرية تُسجّل عند فتح التطبيق، وتقارير PDF وCSV للشهر المحدد.
- بيانات تجريبية موسومة يمكن إضافتها ومسحها من الإعدادات.

## البنية

| المسار | المسؤولية |
| --- | --- |
| `lib/database` | إنشاء SQLite وتفعيل المفاتيح الخارجية والفهارس |
| `lib/repositories` | الحفظ والتعديل والحذف والتكرار والبيانات التجريبية |
| `lib/providers` | حالة Provider وتجميع بيانات الشهر |
| `lib/screens` | الشاشات والنماذج والتصدير |
| `web` | الشعار وعامل SQLite والتخزين المؤقت |
| `test` | اختبارات الحساب والتكرار والبيانات التجريبية |

يستخدم التطبيق Material 3 وProvider وsqflite مع امتداد WebAssembly وIndexedDB، وfl_chart للرسوم، وpdf وprinting وcsv للتصدير. جميع المبالغ تُحفظ بالهللة كوحدات صحيحة لتجنّب أخطاء الكسور العشرية.

| الجدول | البيانات والعلاقات |
| --- | --- |
| `categories` | الاسم المترجم والنوع والأيقونة واللون |
| `transactions` | المبلغ والتاريخ والتصنيف والملاحظة ومعرّف التكرار الاختياري |
| `budgets` | الشهر والحد والتصنيف الاختياري، مع قيد فريد لكل نطاق شهري |
| `recurring_transactions` | تاريخ البدء والاستحقاق التالي وحالة القاعدة |
| `app_settings` | اللغة والمظهر والعملة |

المفتاح المركّب لمعرّف التكرار وتاريخ الاستحقاق يمنع التكرار، وتحديث الموعد وإدخال المعاملات يجريان داخل معاملة SQLite واحدة.
